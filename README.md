# ADIDAS SALES ANALYTICS | POWER BI DASHBOARD

## 📊 Project Overview

The **Adidas Sales Analytics Dashboard** is an interactive Power BI project designed to analyse Adidas sales performance across different regions, product categories, and retail channels.

This project transforms raw sales data into meaningful business insights, helping understand revenue trends, profitability, product performance, customer purchasing behaviour, and regional sales distribution.

## 🎯 Project Objectives

- Analyse overall sales revenue and profitability.
- Identify top-performing products and categories.
- Evaluate sales performance across different regions.
- Compare online and retail store performance.
- Understand customer demographics and purchasing behaviour.
- Analyse payment methods and their contribution to sales.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV

## 📁 Dataset Description

The dataset contains Adidas sales transaction records with the following columns:

| Column | Description |
|---|---|
| Order_ID | Unique order identification |
| Order_Date | Date of the transaction |
| SKU | Product stock keeping unit |
| Product_Name | Name of the product |
| Category | Product category |
| Region | Geographical sales region |
| Store_Type | Online or retail store |
| Units_Sold | Number of units sold |
| Unit_Price | Price per unit |
| Discount | Discount applied |
| Revenue | Revenue generated |
| Profit | Profit earned |
| Customer_Age | Customer age |
| Gender | Customer gender |
| Payment_Method | Payment method used |
| image_url | Product image URL |
